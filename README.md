# Entrega 1 - Inventario de Minecraft

## Descripción

Práctica realizada en JavaScript para simular el inventario de un jugador de Minecraft.

El inventario está formado por una matriz de 4 filas y 9 columnas. Cada posición puede contener un objeto o estar vacía (`null`).

## Estructura del proyecto

```text
Proyecto/
├── Entrega1-mineCraft/
│   ├── index.html
│   └── JS/
│       └── script.js
└── UT01/
    └── Apuntes básicos
```

- **Entrega1-mineCraft:** contiene los archivos de la práctica.
- **index.html:** página HTML que enlaza con el archivo JavaScript.
- **JS/script.js:** contiene el código de la aplicación.
- **UT01:** contiene los apuntes básicos de la unidad.

## Funcionalidades

- Mostrar el inventario completo.
- Mostrar la barra de accesos rápidos.
- Buscar objetos.
- Añadir objetos al inventario.
- Mover y combinar objetos.
- Eliminar objetos con confirmación.
- Contar los huecos libres.
- Mostrar el objeto más abundante.

## Tecnologías utilizadas

- HTML5
- JavaScript ES6

La interacción se realiza mediante `prompt()`, `alert()`, `confirm()` y `console.log()`.
